# Seven-minute demo script

Sign in as `doctor@reflect.demo` (Development) or the hosted demo account. Before presenting: Team → **Reset demo data**
so dates are fresh and every patient is assigned to you.

| Time | Page | Say / do |
|---|---|---|
| 0:00 | Dashboard | "This is what a clinician sees between sessions. Sam Patel is quieter than last week (no sessions this week against several the week before). Casey's latest mood is below their own baseline." Point at the counts, not a diagnosis. |
| 1:00 | Casey Nguyen → Overview | Emotional trajectory against Casey's own rolling baseline. "Compared with self, not a population norm." Open **Programs used**: which Reflect programs Casey uses, with last-30-day counts, and which are not yet tried. |
| 2:00 | Follow-ups | Add "Check in about grief journaling", due tomorrow. "Only I can see this; it keeps a history." |
| 2:45 | Timeline | Filter Program = one of the programs shown (for example Explore Emotions). "Sessions by Reflect program, from the official module catalog." |
| 3:30 | Weekly digest | Print preview: quieter people, below-baseline, follow-ups due, programs used. |
| 4:15 | Messages | Queue a calm nudge to Sam. Paste a phone number to show identifiers removed. "Prototype: queued, not delivered. Pushes would carry no patient information." |
| 5:00 | Team (admin) | Invite a provider, copy the one-time link, accept it in a private window, assign Sam to them, show the audit trail with IDs only. |
| 6:00 | Settings → Sign-in security | Add an authenticator app; show recovery codes. |
| 6:30 | Privacy & trust | Walk the safeguards: what is in place, what is a production target, what is not claimed. |
| 7:00 | Assistant bubble | Ask "What does Hope Tree do?" (prepared answers, no outside call). |

Honest lines to keep ready: synthetic data only; no BAA; messages and invites are prototype in-memory; email delivery needs SMTP.
